# Contact List Flutter UI

A UI-only Flutter implementation of the supplied Contact List reference image.

## Requirements

- Flutter SDK
- Dart SDK included with Flutter

## Run

```bash
flutter pub get
flutter run
```

## Notes

The project intentionally contains no contact storage, add-contact logic, or phone-call functionality. It implements the requested UI using `TextFormField`, `ElevatedButton`, `Card`, and `ListTile`.
